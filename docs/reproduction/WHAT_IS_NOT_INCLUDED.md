# What Is Not Included

The base infra branch intentionally excludes:

- Mascar M1-M4 mechanism source code.
- Mascar configs and diagnostic configs.
- `configs/hrl-repro/SM7_QV100_mascar_*`.
- Mascar experiment results.
- `experiments/paper-mascar/`.
- Mascar reports such as `docs/papers/mascar_w*.md`.
- Raw logs.
- Review packs and `*_review_pack_*` archives.
- Paper-specific data outputs.

This branch is infrastructure only.
