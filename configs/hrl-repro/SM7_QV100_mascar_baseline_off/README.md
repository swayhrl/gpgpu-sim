# SM7_QV100_mascar_baseline_off

Focused-validation baseline comparator for the Mascar M5 matrix.

- `gpgpu_enable_mascar=0`
- Mascar mechanisms are disabled.
- The config is copied from `SM7_QV100_mascar_noop_off`.
- Architecture remains the local SM7/QV100-style setup, not the paper's
  GTX480/Fermi setup.

Use this only as a local focused-validation baseline against the M1-M4 configs.
