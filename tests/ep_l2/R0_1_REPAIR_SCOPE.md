FT access uses ft_physical_cycle() for payload-bank operations and WB/WAD
births; native Tag time retains memcpy offset. The arbiter refuses backwards
FT physical clocks. Existing fill/response/lower callers supply physical GPU
time; RO/TVD integrations must use the same source, never native Tag time.

Host prefill is untimed initialization of a quiescent, clean selected owner.
Its production partition gate requires actual request/response/lower hardware
closure, not merely empty MSHRs. Before mutation it rejects dirty victim or
dirty same-line overwrite, pending/WAD/pinned owners, invalid masks and missing
landing. It never sends a free WB or discards dirty state. Unsupported host
interleaving fails explicitly rather than broadening the oracle/input scope.
Normal timed GPU dirty eviction remains the WB path and must pass tests.

Preview and native Tag fill use the same unchanged victim selection; allocator
mutation does not change Tag selection state. Post-fill asserts that the actual
Tag index equals the reserved index. Partial/repeated prefill keeps the same
handle and existing ready sectors; only initialized sectors become version-zero
symbols. These are dataless reference labels, not numerical payload contents.

The FT GPU memcpy caller also preserves full-width addresses and visits every
intersected 32B sector, including nonaligned endpoints. The previous unsigned
temporary truncated high trace pointers; this is part of binding host Tag and
Payload to the actual same address. The old non-FT loop/delegate is unchanged.
No physical bank op is generated by host initialization. Data budget, banks,
ports, finite WBUF, WAD, descriptor and lower resources are unchanged.

New tests:

- test_ft_memcpy_clock: real partitions, offset0/4096, B/U and C8/C16, warm hit,
  actual per-bank grant deltas, WB staging/WAD distinction and full drain.
- test_ft_host_prefill: actual GPU memcpy and native partition paths, high
  addresses, nonaligned/zero/partial/repeated sectors, generation/index reuse,
  later quiescent epoch, clean eviction/miss/fill, dirty refusal with no state
